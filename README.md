# 부모님 장기요양 본인부담 계산기 — 강아지 버전

**마케팅지니 (MARKETING JINI)** 가 보호자에게 무료로 드리는 휴대폰용 계산기예요. 강아지 '보리'가 말풍선으로 안내해요. 홈 화면에 추가하면 앱처럼 쓸 수 있어요(PWA).
2026.1.1. 국민건강보험공단 고시 기준이에요.

## 파일 설명
| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 내용(글자·구조). 강아지 그림도 이 안에 있어요 |
| `style.css` | 기본 모양(색·글꼴·카드·표) |
| `nav.css` | 아래 메뉴 바(홈·비용계산·내정보) 모양 |
| `anim.css` | 움직임: 내실 금액 숫자 반짝, 맨 아래 로고 둥실둥실 |
| `dog.css` | 강아지 모양과 움직임(눈 깜빡·귀 팔랑·혀 날름·콩 뛰기), 말풍선, 발바닥 무늬 |
| `app.js` | 계산과 화면 동작. **수가(금액표)는 맨 위 `DATA` 한 곳만** 고치면 돼요 |
| `dog.js` | 강아지 말풍선 문구 |
| `sw.js` | 인터넷 없이도 열리게 저장해 두는 파일. **파일을 고쳐 올릴 때마다 맨 위 `VERSION` 숫자를 하나 올려 주세요** |
| `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png`, `logo.png` | 홈 화면 앱 이름·아이콘·로고 |
| `og.png` | 카카오톡·문자 링크 미리보기 그림 (강아지 그림) |

## 올릴 때 (GitHub Pages)
1. 이 폴더 안의 파일을 **전부** 저장소에 올려요. (`og.png`와 `index.html`은 꼭 함께)
2. 공개 주소가 정해지면 `index.html` 위쪽의 `og:url`, `og:image` 주소를 실제 주소로 바꿔요. (지금은 임시 주소)
3. 카카오톡에 예전 미리보기가 남아 있으면 카카오 개발자 사이트의 "카카오톡 URL 메타정보 관리"에서 캐시를 초기화해요. 그림을 바꿀 때는 `og:image` 주소 끝 `?v=` 뒤 숫자도 바꿔 주세요.
4. 마케팅지니 블로그 주소가 정해지면 `app.js`의 `BLOG_URL`에 넣어요.

## 참고
- 계산 검산·개발용 도구(`check-calc.mjs`, `dev-server.mjs`)는 원래 폴더 `장기요양-계산기`에 있어요.
- 기본(강아지 없는) 버전도 원래 폴더의 `index.html`에 그대로 있어요.
